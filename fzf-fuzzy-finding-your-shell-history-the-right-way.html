fzf: fuzzy-finding your shell history the right way

If you're still hitting the up arrow key to find a command you ran three days ago, you're leaving serious productivity on the table. fzf paired with your shell history turns a frustrating linear search into an instant fuzzy search across every command you've ever typed. Here's how to set it up properly and actually get the most out of it.

Why the Default History Search Sucks

Bash and Zsh both ship with Ctrl+R for reverse history search. It works, but it's sequential — you type a search term, and if the first match isn't what you want, you hit Ctrl+R again, and again, cycling through one result at a time. You need to remember exactly how you phrased a command to find it. That's a terrible interface for human memory.

fzf replaces this with a full-text fuzzy finder that shows all matches in a scrollable list, ranked by relevance. Type docker and you instantly see every Docker command you've ever run. Narrow it down with docker run pg and you're at the Postgres container command you want.

Installation

On macOS with Homebrew:

brew install fzf
$(brew --prefix)/opt/fzf/install

On Debian/Ubuntu:

sudo apt install fzf

The install script at the end is important — it sets up the shell keybindings and completions. Run it, say yes to everything, then restart your shell or source your config file.

The Keybinding That Changes Everything

Once fzf is installed and the keybindings are active, press Ctrl+R in your terminal. Instead of the default reverse search, you get an interactive fuzzy finder over your entire history. Start typing anything — partial words, out-of-order fragments — and the list filters live.

A few things that aren't obvious at first:

  • You can type words in any order. kubectl prod apply finds kubectl apply -f deployment.yaml --context=prod.
  • Use Ctrl+N / Ctrl+P (or arrow keys) to move through results.
  • Press Enter to execute, or Tab to paste the command into your prompt without running it — useful when you want to edit it first.
  • Prefix a search term with ! to exclude results. !sudo grep finds grep commands that aren't sudo.

Tuning fzf for History Specifically

The default fzf configuration is generic. For history search, you want to tweak a few things. Add these to your ~/.bashrc or ~/.zshrc:

# Show more results and preview context
export FZF_CTRL_R_OPTS="
  --height 40%
  --layout=reverse
  --info=inline
  --border
  --bind 'ctrl-y:execute-silent(echo -n {2..} | pbcopy)+abort'
"

The ctrl-y binding copies the selected command to your clipboard without executing it — handy when you're on a remote server and want to paste the command locally. On Linux, swap pbcopy for xclip -selection clipboard or wl-copy on Wayland.

Deduplicating History

Fuzzy search over 50 copies of ls -la is noise. Configure your shell to store only unique history entries:

# Bash
export HISTCONTROL=ignoreboth:erasedups
export HISTSIZE=100000
export HISTFILESIZE=200000

# Zsh
setopt HIST_IGNORE_ALL_DUPS
setopt HIST_SAVE_NO_DUPS
HISTSIZE=100000
SAVEHIST=100000

Bump those history sizes up too. Disk space is cheap; losing the exact ffmpeg command that finally worked is not.

Going Further: atuin

If you want to go deeper, look at atuin. It replaces your shell history backend entirely with a SQLite database, gives you context-aware search (filter by directory, host, exit code), and optionally syncs history across machines end-to-end encrypted. It also hooks into Ctrl+R, so the muscle memory stays the same.

That said, fzf alone covers 90% of the use case with zero overhead.

One More Trick: fzf as a Directory Jumper

While you're here — Alt+C (fzf's second major binding) fuzzy-finds directories under your current location and cds into the selected one. No more cd ../../projects/client/backend/src typed by hand. Combined with Ctrl+R, these two bindings alone are worth the install.

# Optional: include hidden dirs and configure the file finder
export FZF_ALT_C_COMMAND="find . -type d -not -path '*/\.git/*'"

The Bottom Line

Install fzf, run the install script, bump your history size, and add the dedup settings. That's maybe ten minutes of work. After that, finding any command you've ever run is a Ctrl+R and a few keystrokes away. It's one of those tools you install and then can't imagine working without.
