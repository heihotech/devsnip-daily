A 10-line Python script to rename files in bulk safely

Renaming a hundred files by hand is the kind of task that makes you question your career choices. Whether you're cleaning up a photo dump, normalizing log file names, or batch-converting underscores to hyphens, doing it manually is slow and error-prone. Here's a tight Python script that handles bulk renaming safely — with a dry-run mode so you don't accidentally nuke your files before you know it's working.

The Script

Drop this into a file called bulk_rename.py:

import os
import sys

def bulk_rename(directory, old, new, dry_run=True):
    renamed = 0
    for filename in os.listdir(directory):
        if old in filename:
            new_name = filename.replace(old, new)
            src = os.path.join(directory, filename)
            dst = os.path.join(directory, new_name)
            if dry_run:
                print(f"[DRY RUN] {filename} → {new_name}")
            else:
                os.rename(src, dst)
                print(f"Renamed: {filename} → {new_name}")
                renamed += 1
    if not dry_run:
        print(f"\nDone. {renamed} file(s) renamed.")

directory = sys.argv[1]
old_str  = sys.argv[2]
new_str  = sys.argv[3]
live_run = len(sys.argv) > 4 and sys.argv[4] == "--go"

bulk_rename(directory, old_str, new_str, dry_run=not live_run)

That's 20 lines if you count the blanks, but the actual logic is ten. The key design decision is dry-run by default. You have to explicitly pass --go to commit changes. This one habit will save you from yourself more than once.

How to Use It

Step 1: Preview what would change

Say you have a folder full of files named like report_2024_jan.csv, report_2024_feb.csv, and you want to swap underscores for hyphens:

python bulk_rename.py ./reports "_" "-"

Output:

[DRY RUN] report_2024_jan.csv → report-2024-jan.csv
[DRY RUN] report_2024_feb.csv → report-2024-feb.csv
[DRY RUN] report_2024_mar.csv → report-2024-mar.csv

Nothing touched yet. You can look at the list, confirm it looks right, and then commit.

Step 2: Actually rename the files

python bulk_rename.py ./reports "_" "-" --go

Now it runs for real. Files are renamed, and you get a count at the end.

Why Dry-Run by Default Matters

I've seen people write rename scripts that just execute immediately. The problem is str.replace() is greedy — it replaces every occurrence of the substring. If your pattern appears in a part of the filename you didn't expect, you'll get weird results. With dry-run mode, you catch that before it's a problem.

Example: you want to rename files with log in the name, replacing it with record. You run the dry-run and notice it's also catching catalog_export.csv. Oops. You tighten your pattern, run again, and only then commit. That's the workflow dry-run enables.

Common Use Cases

  • Photo organization: Replace spaces with underscores in a camera dump — " " "_"
  • Lowercasing extensions: Swap .JPG for .jpg after importing from an older camera
  • Version cleanup: Strip _v1 or _final suffixes from a design folder (we've all been there)
  • Log normalization: Rename error-log to err-log across a whole directory of rotated logs
  • Removing prefixes: Drop a common prefix like 2024_backup_ from a batch of archived files

Extending It

The script is intentionally minimal so it's easy to adapt. A few quick additions worth considering:

Add regex support

Swap filename.replace(old, new) for re.sub(old, new, filename) and import re. Now your pattern argument can be a full regular expression. Useful for stripping date stamps or version numbers that vary.

Handle subdirectories

Replace os.listdir() with os.walk() if you need to recurse into nested folders. Be extra careful with dry-run when you do this — the file count gets large fast and mistakes compound.

Log the changes

Before renaming, write each src → dst pair to a text file. That gives you an undo reference if something goes sideways. os.rename(dst, src) reverses any individual rename if needed.

One Gotcha to Know About

os.rename() will silently overwrite an existing file on some operating systems (Linux, macOS). If two source files would resolve to the same destination name, you'll lose one. Before going live on anything important, either check for collisions manually during the dry-run output or add a quick os.path.exists(dst) guard and skip with a warning.

Bulk renaming doesn't need to be scary. Ten lines, a dry-run flag, and a quick sanity check before you commit — that's the whole workflow. Copy this script somewhere on your path, and the next time you're staring down a folder of badly named files, you'll have it handled in under a minute.
