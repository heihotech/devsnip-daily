A tiny bash function to jump between git branches faster

If you work across multiple branches daily, you already know the friction: git checkout, tab-complete, realize you can't remember if it was feature/auth-refactor or feature/refactor-auth, run git branch, scroll, copy, paste. It adds up. Here's a small bash function I've been using for a while that cuts that loop down significantly using fzf for fuzzy branch selection.

What we're building

A shell function called gbr (short for "git branch") that lists your local branches in a fuzzy finder and checks out whichever one you pick. No arguments needed. Just type gbr, start typing part of a branch name, hit Enter. Done.

If you don't have fzf installed yet, grab it now — it's one of those tools you'll wonder how you lived without:

# macOS
brew install fzf

# Ubuntu/Debian
sudo apt install fzf

The function

gbr() {
  local branch
  branch=$(git branch --sort=-committerdate | grep -v '^\*' | sed 's/^[[:space:]]*//' | fzf --height=20 --prompt="branch: ")
  [ -n "$branch" ] && git checkout "$branch"
}

Drop this into your ~/.bashrc or ~/.zshrc and source it (source ~/.bashrc).

Breaking it down

Sorting by most recently used

git branch --sort=-committerdate lists branches in reverse chronological order by their last commit. This matters more than alphabetical order because the branch you want is almost always one you touched recently. Your main and develop branches might be old commits, so they fall to the bottom — which is exactly where you want them in a jump function like this.

Stripping the current branch indicator

grep -v '^\*' removes the line with the asterisk that marks your current branch. No point jumping to the branch you're already on. The sed command strips leading whitespace so fzf gets clean branch names without extra spaces causing issues on checkout.

The fzf options

--height=20 keeps the picker compact — it shows up inline rather than taking over your whole terminal. --prompt="branch: " is optional but gives you a visual cue. Adjust both to taste.

A few variants worth knowing about

Include remote branches

If you frequently jump to remote branches you haven't checked out locally yet, swap git branch for git branch -a and strip the remotes/origin/ prefix:

gbra() {
  local branch
  branch=$(git branch -a --sort=-committerdate \
    | grep -v '^\*' \
    | sed 's/^[[:space:]]*//' \
    | sed 's|remotes/origin/||' \
    | sort -u \
    | fzf --height=20 --prompt="branch (all): ")
  [ -n "$branch" ] && git checkout "$branch"
}

The sort -u deduplicates entries that appear as both local and remote.

Show the last commit message as a preview

Once you have a lot of branches, names alone aren't always enough. Add a preview pane that shows the tip commit:

gbr() {
  local branch
  branch=$(git branch --sort=-committerdate | grep -v '^\*' | sed 's/^[[:space:]]*//' \
    | fzf --height=30 \
          --prompt="branch: " \
          --preview="git log --oneline -10 {}")
  [ -n "$branch" ] && git checkout "$branch"
}

Now as you move through the list, you see the last 10 commits for each branch on the right side. Useful when you're trying to remember if fix/login-bug was the one with the session token work or the redirect fix.

Making it even faster

A function is great, but two keystrokes beat five. Add an alias on top of the function:

alias gb='gbr'

Now gb is your branch switcher. Muscle memory builds fast.

  • Type gb to open the picker
  • Type a few letters to fuzzy-filter
  • Arrow keys or keep typing to narrow down
  • Hit Enter to checkout
  • Hit Escape or Ctrl-C to cancel without switching

One thing to watch

If you're in a repo with a detached HEAD state, git branch will behave a bit oddly — you'll see (HEAD detached at ...) in the output. The grep -v '^\*' handles it because Git marks that line with an asterisk too, so it gets filtered out cleanly.

This is a small thing but it's one of those quality-of-life improvements that compounds. The less friction between you and your work, the better. Spend five minutes wiring this up and you'll stop thinking about branch switching entirely.
